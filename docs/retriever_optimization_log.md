# 关键词检索优化记录

## 优化内容

将 `count_keyword_hits` 函数从"判断关键词是否出现"改为"统计关键词出现次数"。

```python
# 改前：只判断有没有出现，出现一次和十次得分一样
if kw in text:
    hits += 1

# 改后：数出现了几次，出现越多得分越高
hits += text.count(kw)
```

---

## 结论

1. 只改了一行代码，把 `if kw in text: hits += 1` 改成 `hits += text.count(kw)`
2. 目录页排前面的问题基本解决，不需要额外做目录页降权
3. 正文页因为关键词出现次数多，自然排到前面
4. 剩余问题：仍然是纯关键词匹配，不理解语义（比如查"最速下降法"找不到"梯度下降"的内容）
